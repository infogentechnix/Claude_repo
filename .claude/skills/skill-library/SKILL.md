# ECC skill library

This repo installs only the ECC components it uses every day: Python, LLM API clients, Arcads ad and content work, and Claude Code harness upkeep. These are the DAILY set. Everything else from ECC 2.2.3 is kept here as LIBRARY, available on demand but not loaded into every session.

## How to use a library entry

1. Find the entry in the groups below.
2. Skill: read `.claude/skill-library/skills/<name>/SKILL.md` and follow it as if it were installed. Paths that skill mentions, such as `references/`, are relative to its folder in the library.
3. Agent: read `.claude/skill-library/agents/<name>.md`, then run it through the Agent tool with `subagent_type: "general-purpose"`, using the file body as the prompt preamble.
4. Command: read `.claude/skill-library/commands/<name>.md` and carry out its steps.
5. If an entry is needed every day, promote it so it loads in every session. Add it to the ECC install with `install.sh --target claude-project ... --skills <name>` (see the ECC section of CLAUDE.md), then rerun the `agent-sort` skill.
